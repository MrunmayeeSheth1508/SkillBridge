# SkillBridge

**Evidence-aware, transfer-aware skill gap analysis and learning roadmaps, computed inside PostgreSQL.**

SkillBridge combines O*NET, ESCO and SkillSpan to tell a learner what a target career needs, which source says so, how far they are from it, which skills they already have that transfer, and in which order, week by week and with which courses, to close the gap. PostgreSQL is the computation engine (functions, triggers, recursive CTEs, materialized views, row-level security). Flask and Chart.js are only the presentation layer.

## Contributions
1. **Evidence-aware requirements.** Each career-skill requirement keeps its provenance (O*NET ratings, O*NET technology, ESCO essential/optional, job postings). The requirements are aggregated with confidence weights, and source agreement is measured by tier with Cohen's κ (RQ1).
2. **Directional skill transfer.** T(a→b) = sim^α · P(b|a)^β gives partial credit for related skills. It is evaluated on held-out occupations (RQ2).
3. **Prerequisite-valid, time-budgeted roadmaps.** A trigger keeps the prerequisite graph acyclic (with advisory locks for concurrency). Roadmaps are layered by longest path, and courses are chosen by greedy weighted set cover, which is compared with the exact ILP optimum (RQ4).
4. **Skill extraction from job postings (NLP).** A lexicon is built in SQL (aliases, derived acronyms, case rules, a learned blocklist) and matched exactly and with pg_trgm fuzzy matching. It is evaluated on SkillSpan (RQ3), and candidates go through an admin review workflow.

## Setup (Windows, VS Code terminal; one command at a time)
```
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```
- Install PostgreSQL 16 and create the database: `createdb -U postgres skillbridge` (or create it in pgAdmin).
- Create `.env` in the project folder containing `DATABASE_URL=postgresql://postgres:<your password>@localhost:5432/skillbridge`. **Never commit `.env`.**
- Put the datasets in `data/raw/`: the O*NET files, the ESCO v1.2.1 zip, the SkillSpan json files and `ONET_ESCO_crosswalk_occupations.csv`.
- If `import psycopg` fails, the loader adds `C:\Program Files\PostgreSQL\16\bin` to PATH automatically. Do not install `psycopg-binary`.

## Curated data you can extend (`data/curated/`)
- `prerequisites.csv`: skill → prerequisite edges. Cycles are rejected by the trigger.
- `learning_resources.csv`: courses with hours and the skills they cover (see `docs/learning_resources_guide.md`). Rebuild after editing.
- `lexicon_blocklist.csv`: generated by `scripts/tune_lexicon.py` on the train split. It is frozen; do not tune on test.

## User study
Follow `docs/user_study/protocol.md`, then save the answers as `docs/user_study/results.csv` and run `python scripts/analyze_user_study.py docs/user_study/results.csv`.

## Security notes
- Each web request runs as `skillbridge_learner` or `skillbridge_admin` (`SET LOCAL ROLE`) with `skillbridge.user_id` set, so row-level security enforces that a learner sees only their own data.
- Passwords are hashed with Werkzeug, and the session secret is kept in `.flask_secret` (git-ignored).
- `.env`, `data/raw/` and `.flask_secret` must never be committed.

## Limitations and future work
Transfer is based on co-occurrence; embedding similarity (pgvector) is the next step. The prerequisite and course data are small and hand-curated. Extraction is lexicon-based; a fine-tuned BERT extractor is future work. The user study is a small convenience sample.
